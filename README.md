# CV — Bastien Dumont

Plain HTML/CSS résumé, one A4 page, in English and French.

| File         | Purpose                                                  |
| ------------ | -------------------------------------------------------- |
| `index.html` | English version                                          |
| `fr.html`    | French version                                           |
| `style.css`  | Shared layout and design tokens (change `--accent` here) |
| `photo.jpg`  | Portrait                                                 |

## Export to PDF

Open a page in Chrome → Print → Save as PDF, with **Margins: None** and **Background graphics** on.
The EN/FR switch is hidden when printing.
